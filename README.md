# 🌱 VerdeGest Angola 2026

Sistema Integrado de Gestão e Vendas para Empresas de Jardinagem e Paisagismo — mercado angolano.

## 🚀 Demo

👉 **[Ver demo ao vivo](https://admyacm-hub.github.io/ao)**

## ✨ Funcionalidades

- 💰 Orçamentador inteligente em Kwanza (AOA)
- 📅 Agendamento com slots reais
- 👥 Portal do cliente (faturas, histórico botânico)
- 📱 PWA offline para equipas de campo
- 🗺️ Otimização de rotas (TSP)
- 📦 Gestão de stock e equipamento
- 📊 Business Intelligence (MRR, Churn, LTV, CAC)
- 🔐 Painéis Admin e Gestor com RBAC
- 🌙 Dark mode automático
- ♿ Acessibilidade WCAG AA
